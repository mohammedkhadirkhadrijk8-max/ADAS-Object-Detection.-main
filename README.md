# Real-Time ADAS Object Detector 🚗

A full-stack computer vision web application simulating an Advanced Driver Assistance Systems (ADAS) perception pipeline. 

**Tech Stack:** Python, Streamlit, YOLOv8 (Ultralytics), OpenCV

**Features:**
- **Video Processing:** End-to-end inference on uploaded dashcam footage.
- **Hardware Integration:** Real-time webcam processing using OpenCV.
- **Dynamic Tuning:** Interactive UI controls for adjusting detection confidence thresholds.

**How to run locally:**
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
